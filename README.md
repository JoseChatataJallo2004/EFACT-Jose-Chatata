# efact-jose-chatata

Proyecto Angular con soporte SSR (Server Side Rendering) y Angular Material, utilizado para pruebas de descarga de PDF, XML y CDR desde un backend con token de autorización.

## Requisitos

- Node.js >= 18
- Angular CLI >= 17
- npm >= 9

## Instalación

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/JoseChatataJallo2004/EFACT-Jose-Chatata.git
   cd efact-jose-chatata

2. Instalar dependencias:
   ```bash
    npm install
